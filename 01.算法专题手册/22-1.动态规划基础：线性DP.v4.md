# 动态规划基础：线性 DP

## 本章目标

训练一维 DP 的第一反应：

> 看到“到当前位置的最优值 / 方案数”，先定义状态，再推导转移。

本章统一采用：

**显式 `dp[]` 数组版 → 理解状态与转移 → 再做空间压缩**

学习阶段不要为了省空间过早使用滚动变量。空间压缩是优化，不是建模本身。

---

## 一、线性 DP 的基本思维

看到一维 DP 时，先按下面顺序思考：

1. `dp[i]` 表示什么？
2. 当前状态 `dp[i]` 依赖哪些旧状态？
3. 状态转移公式是什么？
4. Base Case 如何初始化？
5. 最终答案位于哪里？
6. 是否可以压缩空间？

核心：

> 先让状态“看得见”，再考虑把状态压缩掉。

---

## 二、秒判卡

| 看到什么 | 直接想到 |
|---|---|
| 爬楼梯 / 斐波那契 | 一维 DP |
| 到第 `i` 个位置的最优值 | `dp[i]` |
| 不能选相邻 | 打家劫舍 |
| 最大连续子数组和 | Kadane / 线性 DP |
| 按一位 / 两位解释 | Decode Ways |
| 问所有方案枚举 | 回溯优先，不是 DP 优先 |

# 高频模板 1：基础一维 DP

## 秒判关键词

到第 `i` 步、依赖前几个位置、方案数。

## 母题

LC70 Climbing Stairs

## 状态定义

```text
dp[i] = 到达第 i 阶楼梯的方法数
```

## 状态转移

到达第 `i` 阶，最后一步只有两种可能：

- 从 `i - 1` 走 1 步
- 从 `i - 2` 走 2 步

所以：

```text
dp[i] = dp[i - 1] + dp[i - 2]
```

## 标准代码：显式 DP 数组

```java
public int climbStairs(int n) {
    if (n <= 2) return n;

    int[] dp = new int[n + 1];
    dp[1] = 1;
    dp[2] = 2;

    for (int i = 3; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }

    return dp[n];
}
```

## 空间优化

因为 `dp[i]` 只依赖 `dp[i - 1]` 和 `dp[i - 2]`，所以可以压缩成两个变量：

```java
public int climbStairsOptimized(int n) {
    if (n <= 2) return n;

    int prev2 = 1;
    int prev1 = 2;

    for (int i = 3; i <= n; i++) {
        int cur = prev1 + prev2;
        prev2 = prev1;
        prev1 = cur;
    }

    return prev1;
}
```

## 一句话记忆

当前答案来自前一步和前两步。

## 高频变体

| 题目 | 变化点 |
|---|---|
| LC746 Min Cost Climbing Stairs | 当前取前两个状态中的最小代价 |
| LC509 Fibonacci Number | 同样只依赖前两个状态 |
| LC91 Decode Ways | 按一位 / 两位合法性转移 |

## 常见坑点

- 先写清楚 `dp[0]`、`dp[1]` 或题目对应的 Base Case。
- 不要一开始就写滚动变量。
- 空间压缩前先确认当前状态到底依赖哪些旧状态。

# 高频模板 2：打家劫舍

## 秒判关键词

不能选相邻、选或不选、最大金额。

## 母题

LC198 House Robber

## 状态定义

推荐学习阶段先使用：

```text
dp[i] = 偷到第 i 间房时，在前 i + 1 间房中能够获得的最大金额
```

对于第 `i` 间房有两个选择：

- 不偷当前房：得到 `dp[i - 1]`
- 偷当前房：得到 `dp[i - 2] + nums[i]`

所以：

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

## 标准代码：显式 DP 数组

```java
public int rob(int[] nums) {
    int n = nums.length;

    if (n == 1) return nums[0];

    int[] dp = new int[n];
    dp[0] = nums[0];
    dp[1] = Math.max(nums[0], nums[1]);

    for (int i = 2; i < n; i++) {
        dp[i] = Math.max(
            dp[i - 1],
            dp[i - 2] + nums[i]
        );
    }

    return dp[n - 1];
}
```

## 空间优化

因为 `dp[i]` 只依赖前两个状态：

```java
public int robOptimized(int[] nums) {
    int prev2 = 0;
    int prev1 = 0;

    for (int x : nums) {
        int cur = Math.max(prev1, prev2 + x);
        prev2 = prev1;
        prev1 = cur;
    }

    return prev1;
}
```

## 一句话记忆

当前房只有两个选择：

> 偷当前房，或者不偷当前房。

## 高频变体

| 题目 | 变化点 |
|---|---|
| LC213 House Robber II | 环形数组，拆成两段 |
| LC740 Delete and Earn | 按值聚合后变成打家劫舍 |
| LC337 House Robber III | 树上选点，转树形 DP |

## 常见坑点

- 环形不能同时选头尾。
- 先把“选 / 不选”的含义转成明确的 `dp[i]`。
- `take / skip` 是一种状态表达，但学习初期优先先掌握数组状态。

# 高频模板 3：最大连续子数组和

## 秒判关键词

连续子数组、最大和、可以从当前位置重新开始。

## 母题

LC53 Maximum Subarray

## 状态定义

```text
dp[i] = 以 nums[i] 结尾的连续子数组最大和
```

注意：

> 必须包含 `nums[i]`。

这是状态定义中最重要的限制。

## 状态转移

对于 `nums[i]`：

- 接在前面的连续子数组后面：`dp[i - 1] + nums[i]`
- 从当前位置重新开始：`nums[i]`

所以：

```text
dp[i] = max(nums[i], dp[i - 1] + nums[i])
```

最终答案不一定是 `dp[n - 1]`，而是：

```text
max(dp[0], dp[1], ..., dp[n - 1])
```

## 标准代码：显式 DP 数组

```java
public int maxSubArray(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];

    dp[0] = nums[0];
    int ans = dp[0];

    for (int i = 1; i < n; i++) {
        dp[i] = Math.max(
            nums[i],
            dp[i - 1] + nums[i]
        );
        ans = Math.max(ans, dp[i]);
    }

    return ans;
}
```

## 空间优化：Kadane

因为 `dp[i]` 只依赖 `dp[i - 1]`：

```java
public int maxSubArrayOptimized(int[] nums) {
    int cur = nums[0];
    int ans = nums[0];

    for (int i = 1; i < nums.length; i++) {
        cur = Math.max(nums[i], cur + nums[i]);
        ans = Math.max(ans, cur);
    }

    return ans;
}
```

## 一句话记忆

前面的贡献如果不如重新开始，就从当前元素重新开始。

## 高频变体

| 题目 | 变化点 |
|---|---|
| LC152 Maximum Product Subarray | 同时维护最大值和最小值 |
| LC121 Best Time to Buy and Sell Stock | 可转成最大差值 |
| LC918 Maximum Sum Circular Subarray | 环形最大子数组 |

## 常见坑点

- 全负数组不能把答案初始化成 0。
- 子数组必须连续。
- `dp[i]` 不是“前 i 个数字中的最大子数组和”，而是“以 i 结尾”。

# 高频模板 4：解码方法

## 秒判关键词

每个位置可由前一位或前两位转移。

## 母题

LC91 Decode Ways

## 状态定义

```text
dp[i] = 字符串前 i 个字符的解码方法数量
```

这里采用长度语义：

- `dp[0]`：空字符串
- `dp[1]`：前 1 个字符
- `dp[i]`：前 `i` 个字符

## 状态转移

当前位置可能通过两种方式获得：

### 单字符解码

如果第 `i` 个字符不是 `'0'`：

```text
dp[i] += dp[i - 1]
```

### 双字符解码

如果最后两个字符组成的数字在 `[10, 26]`：

```text
dp[i] += dp[i - 2]
```

## 标准代码

```java
public int numDecodings(String s) {
    int n = s.length();
    int[] dp = new int[n + 1];

    dp[0] = 1;
    dp[1] = s.charAt(0) == '0' ? 0 : 1;

    for (int i = 2; i <= n; i++) {
        char one = s.charAt(i - 1);

        if (one != '0') {
            dp[i] += dp[i - 1];
        }

        int two = Integer.parseInt(s.substring(i - 2, i));

        if (two >= 10 && two <= 26) {
            dp[i] += dp[i - 2];
        }
    }

    return dp[n];
}
```

## 一句话记忆

当前位置可以由：

- 最后一位单独合法解码
- 最后两位一起合法解码

共同转移而来。

## 常见坑点

- `'0'` 不能单独解码。
- `10` 和 `20` 合法，但 `30` 不合法。
- 注意这里 `dp[i]` 表示的是“前 i 个字符”，而不是字符串下标 `i`。

# 三、线性 DP 的统一建模方式

遇到陌生题时，不要先找模板。

依次问：

```text
1. dp[i] 表示什么？
2. 为什么一个 i 就足够描述状态？
3. 当前状态的最后一步 / 最后一次选择是什么？
4. dp[i] 来自哪些旧状态？
5. 初始状态是什么？
6. 最终答案一定是 dp[n - 1] 吗？
7. 能否压缩空间？
```

---

# 四、高频坑点

| 坑点 | 正确反应 |
|---|---|
| 状态没定义就写转移 | 先说清楚 `dp[i]` 的含义 |
| 初始化错误 | 单独处理 Base Case |
| 把状态定义得太宽泛 | 加上“以 i 结尾 / 前 i 个 / 必须选 i”等约束 |
| 全负最大子数组 | 答案初始化为 `nums[0]` |
| 环形打家劫舍 | 拆成两段 |
| 过早空间优化 | 先写数组版 |
| 只会背滚动变量 | 先还原完整 `dp[]` |

---

# 五、空间压缩原则

只有当完整 DP 已经建立清楚之后，再考虑空间压缩。

判断方法：

> `dp[i]` 到底需要多久以前的状态？

例如：

```text
只依赖 dp[i - 1]
→ 一个滚动变量

只依赖 dp[i - 1]、dp[i - 2]
→ 两个滚动变量

依赖更多历史状态
→ 不能简单压成常数空间
```

空间优化改变的是：

> 存储方式

而不是：

> 状态转移逻辑

---

# 六、面试速记

1. 先说状态：`dp[i]` 是什么。
2. 再说当前状态从哪些旧状态来。
3. 写出状态转移。
4. 明确 Base Case。
5. 判断最终答案位置。
6. 最后再考虑空间压缩。

一句话：

> **DP 先建模，后优化。**
